# EcoShift — Аналитическое ядро производственного планировщика

**Статус:** рабочий учебный прототип. Данные — модельные.

## Что уже реализовано

- Чтение производственных операций, параметров станков и почасовых тарифов из CSV.
- Построение **базового расписания**: раннее допустимое размещение операций с приоритетом ранних дедлайнов.
- **Математическая оптимизация** стоимости электроэнергии с дискретностью 30 минут.
- Ограничения: один станок — одна операция; предшествование; время доступности; дедлайны; ограничение суммарной мощности; единый конец смены.
- Независимая проверка корректности двух расписаний.
- Расчёт стоимости, потреблённой энергии, пиковой мощности, времени завершения.
- Диаграммы Ганта, график нагрузки, диаграмма затрат, CSV-экспорт результатов.
- Сценарий с заранее указанным временем недоступности станка.

## Быстрый запуск на Windows 11

Нужен установленный **Python 3.12 (64-разрядный)**.

1. Распакуйте архив в любую обычную папку. Откройте терминал в папке `EcoShift_MVP_01`.
2. Установите зависимости:

```powershell
py -3.12 -m pip install -r requirements.txt
```

3. Запустите основной сценарий:

```powershell
py -3.12 ecoshift.py
```

4. Запустите сценарий с недоступностью станка:

```powershell
py -3.12 ecoshift.py --downtime data/downtime_example.csv --output results_downtime
```

5. Проверьте программу тестами:

```powershell
py -3.12 -m unittest -v
```

На macOS / Linux вместо `py -3.12` обычно используется `python3` или `python3.12`.

> Если Python добавлен в PATH и работает обычная команда `python`, можно заменить `py -3.12` на `python`.

## Как интерпретировать входные данные

### `config.json`

- `day_start_hour`: 8 — временной отсчёт начинается в 08:00.
- `day_end_hour`: 24 — горизонт анализа заканчивается в 00:00 следующих суток.
- `slot_minutes`: 30 — дискретность расчёта.
- `latest_completion_hour`: 22 — все работы должны завершиться не позднее 22:00.
- `power_cap_kw`: 14 — ограничение суммарной активной мощности, кВт.
- `solver_time_limit_seconds`: 20 — ограничение времени поиска.

### `operations.csv`

- `duration_slots`: продолжительность операции в 30-минутных интервалах. Например, `3` = 90 минут.
- `release_slot`: самое раннее начало операции; 0 соответствует 08:00, 4 соответствует 10:00.
- `deadline_slot`: самое позднее завершение; 16 = 16:00, 28 = 22:00, 32 = 00:00 следующего дня (но общий конец смены в конфиге — 22:00).
- `predecessor`: ID операции, которая должна завершиться раньше данной; пустое значение означает отсутствие зависимости.

### `tariffs.csv`

Каждая строка задаёт почасовой тариф за 1 кВт·ч для периода `[start_hour, end_hour)`. Интервалы не должны пересекаться и должны полностью покрывать горизонт.

### `downtime_example.csv`

В сценарии недоступности станок `M2` недоступен в слотах 16–19 включительно (16:00–18:00). Оптимизатор не назначит операцию на интервал, пересекающий это время. **Это сценарное перепланирование с заранее известным простоем**, а не работающая в реальном времени система диспетчеризации.

## Математика

Для каждого задания `i` и допустимого начала `s` используется бинарная переменная `x[i,s] ∈ {0,1}`.

Цена расписания:

`C = Σ_t тариф[t] × суммарная_мощность[t] × Δt`.

Основная цель — минимизировать `C`. Для решений с одинаковой ценой дополнительно выбираются более ранние старты. Решатель — **SciPy/HiGHS (MILP)**. По завершении программа отдельно проверяет допустимость результата.

## Зафиксированные результаты демонстрационного набора

Основной сценарий (11 операций, 3 станка, тариф 10/7/5/3 руб./кВт·ч, смена до 22:00, лимит 14 кВт):

| Показатель | Базовый вариант | EcoShift |
|---|---:|---:|
| Стоимость | 645,00 руб. | 372,50 руб. |
| Энергия | 70,5 кВт·ч | 70,5 кВт·ч |
| Пиковая мощность | 14 кВт | 14 кВт |
| Последняя операция завершена | 15:00 | 22:00 |

**Выигрыш — 272,50 руб. (42,2%)** на данном *искусственном* наборе. При этом EcoShift откладывает некоторые работы: начало/завершение смены и стоимость ожидания имеют значение для экономической оценки. Мы пока не моделируем зарплату персонала, стоимость хранения незавершённого производства, пусковые потери, амортизацию и штрафы за другие виды задержек. Отсутствие этих факторов влияет на интерпретацию результата.

Сценарий с недоступностью `M2` в 16:00–18:00: стоимость EcoShift — **378,50 руб.**, разница с исходной жадной схемой — **41,3%**.
